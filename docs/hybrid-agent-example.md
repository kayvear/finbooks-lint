## Comparison Code Written by the Agent

This code was generated by the specialist agent via `python_repl` during the run above.
It is not part of the source tree — the agent wrote it from the system prompt description alone.

```python
import json

# Data loaded from read_pdf_raw / read_books_raw tool responses
extracted = json.loads(extracted_raw)
books     = json.loads(books_raw)

breaks    = []
TOLERANCE = 0.02

# ── CHECK 1: Equity allocation vs books ──────────────────────────────────────
equity_row = next(
    r for r in extracted["sections"]["asset_allocation"]["rows"]
    if "equit" in r["fields"]["Asset Class"]["raw_text"].lower()
)
pdf_equity   = equity_row["fields"]["Value"]["parsed_value"]   # 840.37 (injected)
books_equity = books["equity_value"]                            # 800.35
delta_eq     = abs(pdf_equity - books_equity)                  # 40.02

if delta_eq > TOLERANCE:
    breaks.append({
        "break_type": "numeric_footing",
        "section":    "asset_allocation",
        "field":      "equity_value",
        "pdf_value":  pdf_equity,
        "books_value": books_equity,
        "delta":      round(delta_eq, 4),
        "severity":   "high",
        "description": f"PDF equity allocation ${pdf_equity:.2f} does not match "
                       f"books equity value ${books_equity:.2f} (delta ${delta_eq:.2f}).",
    })

# ── CHECK 2: Missing / extra positions ───────────────────────────────────────
pdf_symbols   = {r["fields"]["Symbol"]["raw_text"]
                 for r in extracted["sections"]["positions"]["rows"]}
books_symbols = {p["symbol"] for p in books["positions"]}
# pdf_symbols = {'V'},  books_symbols = {'V', 'CRM', 'GOOGL'}

for sym in books_symbols - pdf_symbols:          # CRM, GOOGL → missing from PDF
    breaks.append({
        "break_type":  "missing_extra_data",
        "section":     "positions",
        "field":       "row",
        "pdf_value":   None,
        "books_value": sym,
        "delta":       None,
        "severity":    "high",
        "description": f"Position '{sym}' is present in books but missing from the PDF statement.",
    })

for sym in pdf_symbols - books_symbols:          # nothing extra in this case
    breaks.append({
        "break_type":  "missing_extra_data",
        "section":     "positions",
        "field":       "row",
        "pdf_value":   sym,
        "books_value": None,
        "delta":       None,
        "severity":    "high",
        "description": f"Position '{sym}' appears in the PDF statement but is not found in books.",
    })

# ── CHECK 3: Cash closing balance sum vs books ───────────────────────────────
# Agent summed banking_cash rows directly — caught missing savings account
# Fixed comparator checked via asset_allocation Cash row (which was absent from PDF)
pdf_cash  = sum(
    r["fields"]["Closing Balance"]["parsed_value"]
    for r in extracted["sections"]["banking_cash"]["rows"]
    if r["fields"].get("Closing Balance", {}).get("parsed_value") is not None
)
# pdf_cash  = 24520.41  (only Checking account extracted)
# books_cash = 38845.27 (Checking 24520.41 + Savings 14324.86)
books_cash = books["cash_value"]
delta_cash = abs(pdf_cash - books_cash)          # 14324.86

if delta_cash > TOLERANCE:
    breaks.append({
        "break_type":  "numeric_footing",
        "section":     "banking_cash",
        "field":       "cash_value",
        "pdf_value":   pdf_cash,
        "books_value": round(books_cash, 2),
        "delta":       round(delta_cash, 4),
        "severity":    "high",
        "description": f"PDF cash total ${pdf_cash:.2f} does not match "
                       f"books cash value ${books_cash:.2f} (delta ${delta_cash:.2f}).",
    })

# ── CHECK 4: Positions numeric footing ───────────────────────────────────────
# totals_row is null in extracted data — agent correctly skipped this check
total_rows = [
    r for r in extracted["sections"]["positions"]["rows"]
    if r["fields"]["Symbol"]["raw_text"].upper() in ("TOTAL", "TOTALS")
]
# len(total_rows) == 0 → skipped

result = breaks   # picked up by python_repl as RESULT_JSON
```

## Why the Fixed Comparator Missed the Cash Break

The fixed `StatementComparator` checks cash by reading the `asset_allocation` Cash row value
and comparing it to `books.cash_value`. The injected PDF for this customer had the asset
allocation section partially extracted — only the Equities row came through. With no Cash row
present, the comparator skipped the check entirely.

The hybrid agent took a different path: it summed `banking_cash.rows[*].Closing Balance`
and compared that directly to `books["cash_value"]`. This worked regardless of what the
asset allocation section contained, and revealed that the savings account row was missing
from the extracted statement.
